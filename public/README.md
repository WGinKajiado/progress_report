## Overview
# Construction Progress Report Generator

A web-based tool for generating weekly construction site progress reports. This project allows users to enter project details, track work progress, and preview and print professional reports with ease. The reports are designed to document site activities, upcoming works, and tradesmen on site, ensuring transparency and efficient communication.

## Features

- User-friendly interface with Tailwind CSS styling.  
- Dynamic preview of reports from saved data (localStorage).  
- Sections included:  
  - Project Information  
  - Work Progress (multiple sections)  
  - Upcoming Works  
  - Tradesmen On Site  
- Print functionality to generate professional reports.  
- Responsive layout for desktop and tablet devices.  

---

## Technologies

- **HTML5 & CSS3**  
- **Tailwind CSS** for styling  
- **Vanilla JavaScript** for dynamic content and localStorage management
